# Απαιτήσεις Συστήματος:
Βεβαιωθείτε ότι έχετε εγκατεστημένη την Python 3.6 ή νεότερη έκδοση. Για την παραγωγή των γραφημάτων απόδοσης, απαιτείται η εγκατάσταση δύο εξωτερικών βιβλιοθηκών (matplotlib και numpy). Μπορείτε να τις εγκαταστήσετε εκτελώντας την παρακάτω εντολή στο τερματικό σας:
```bash
pip install matplotlib numpy
```
Το υπόλοιπο πρόγραμμα βασίζεται αποκλειστικά σε ενσωματωμένες βιβλιοθήκες της Python (hashlib, random, time, sys).
